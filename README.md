# ESH7NLY - النسخة النهائية

## تسجيل الدخول الافتراضي
- اسم المستخدم: `admin`
- كلمة المرور: `1234`

## الموجود في النسخة
- Dashboard رئيسية للمبيعات والتكلفة والربح وحساب عويس.
- أرباح يوم 11 ويوم 26 منفصلة.
- حساب عويس لكل يوم والإجمالي وتسديد كامل الحساب.
- ربح كل تفعيل وحساب التكلفة تلقائيًا حسب الباقة.
- صفحة تجار لعبد الحكيم وأسامة.
- تنبيهات التجديد بالألوان.
- زر واتساب للمشترك.
- بحث وفلاتر حسب الحالة والتاجر والباقة.
- تحذير عند تكرار الرقم.
- تحذير عند البيع بأقل من التكلفة.
- سجل عمليات.
- تصميم مناسب للموبايل والكمبيوتر.
- زر تفعيل سريع.
- تصدير واستيراد نسخة احتياطية.
- تخزين محلي + محاولة مزامنة Firebase.
- اتصالات: قريبًا.

## مهم جدًا بخصوص Firebase
ملف `firebase-rules.json` الموجود هنا قواعده مفتوحة للاختبار فقط، وليست آمنة للاستخدام الحقيقي ببيانات العملاء.
لتأمين الموقع فعليًا يجب تفعيل Firebase Authentication وضبط قواعد Realtime Database على مستخدمين مصرح لهم فقط.

## الرفع على GitHub Pages
ارفع الملفات الموجودة داخل المجلد مباشرة إلى Repository ثم فعّل GitHub Pages من Settings > Pages.
